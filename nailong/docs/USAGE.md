# 奶龙使用文档

## 1. 首次部署

1. 买一台 Ubuntu 20.04+ / Debian 11+ 服务器（x86_64 或 arm64，建议 2 GB 内存、10 GB 以上磁盘）。
2. 打开奶龙，填写：服务器 IP、SSH 端口（默认 22）、用户名（默认 root）、密码（或私钥）。
3. 点 **连接并自动部署**。
4. 首次连接会弹出服务器 **SSH 指纹**，在云厂商控制台执行
   `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 对比一致后点“信任并连接”。
5. App 自动检测环境并给出 **检测报告 + 部署计划**（将安装 / 保留 / 跳过）。确认后点 **确认并开始部署**。
6. 部署页显示每一步的真实进度、下载速度与日志，可随时 **取消**（安全停止，已完成部分保留），失败后可 **继续部署**。
7. **部署在服务器上独立运行**：切到后台、锁屏、断网、甚至 App 被系统回收都不会中断它。回到 App 会自动重连并接上进度；
   如果 App 被回收了，重新打开、再填一次这台服务器的 SSH 信息并连接，会提示“服务器上有一个正在进行的部署”并自动接上，完成后自动配对。
   部署期间通知栏会有“奶龙正在部署服务器”的常驻通知（前台服务），用来降低被系统回收的概率。
   **国产手机建议**：系统设置 → 应用 → 奶龙 → 电池 / 后台，改为“无限制 / 允许后台运行”，并允许通知。
8. 出现 **🎉 部署成功！** 后进入首页。

> 部署完成后 App 改用本机专属密钥连接，SSH 密码默认不保存。

## 2. 已有 AstrBot 的服务器

奶龙会识别已有的 AstrBot / NapCat 容器（包括淋雨面板部署的），报告里显示“保留”：

- 不重装、不覆盖配置、不删除数据；
- 已有 OneBot 连接直接复用，不重置 Token；
- 只安装奶龙 Agent 并完成配对。

## 3. 日常管理

| 页面 | 功能 |
| --- | --- |
| 首页 | AstrBot / NapCat / Docker / 服务器状态，CPU、内存、磁盘，上下行网速，启动/停止/重启、日志、备份 |
| QQ | NapCat 登录二维码（自动刷新状态）、刷新二维码、登录信息，启动/停止/重启 NapCat |
| 插件 | 查看、启用/禁用、更新、卸载、配置、插件日志；从 GitHub 安装（可填版本与 SHA-256）、上传本地 ZIP |
| 日志 | WebSocket 实时日志，AstrBot / NapCat / Agent，级别过滤、搜索、暂停、自动滚动、复制、导出；简洁模式带中文提示，原始模式保留原文 |
| 更多 | Docker 容器、备份恢复、下载加速、服务器管理、设备授权、主题 |

## 4. 下载加速

「更多 → 下载加速」，全部来源由你添加（奶龙不内置第三方镜像站），只接受 HTTPS：

- **GitHub 下载源**：前缀代理（`https://代理/https://github.com/...`）或替换域名。可在服务器上实测延迟、速度、是否支持断点续传（缓存 6 小时）。
- **Docker 镜像加速器**：部署时自动测试可达性、TLS、镜像摘要是否存在、架构是否匹配，按延迟排序；按摘要拉取，不改 Docker 配置、不重启 Docker。
- **PyPI 镜像**：Agent 依赖按哈希安装。
- **Docker 软件源镜像**：安装 Docker 时使用，按官方 GPG 指纹校验。

## 5. 备份恢复

- 备份内容可选：AstrBot 配置、插件、插件数据、NapCat 配置。
- 可下载到手机、从手机上传。上传与恢复前都会逐文件校验 SHA-256。
- 恢复需输入备份文件名确认；会先自动做一次“恢复前备份”。

## 6. 多服务器

「更多 → 服务器管理」：添加、切换、重新连接、重新配对、重命名、删除（只删本机信息）。
服务器重装导致指纹变化时，App 会拒绝连接并提示可能的中间人攻击；确认是重装后可“重新信任主机密钥”。

## 7. 常见问题

| 提示 | 处理 |
| --- | --- |
| 服务器连接失败，请检查 IP 地址和 SSH 端口 | 检查 IP、端口、云安全组是否放行 SSH |
| 用户名或密码错误 | 核对密码；私钥登录确认公钥已在服务器上 |
| 需要 root 权限 | 用 root 登录，或用 sudo 用户并填写密码 |
| Docker 镜像下载失败，正在尝试备用下载源 | 在「下载加速」添加可信镜像加速器后点“继续部署” |
| SSH 服务禁止了端口转发 | 在 `/etc/ssh/sshd_config` 设置 `AllowTcpForwarding yes`（或 `local`）后重启 sshd |
| 连不上服务器（刚输错过几次密码） | 被 Fail2Ban 临时封禁了 IP（1 小时自动解封）。在服务器控制台执行 `fail2ban-client status sshd` 查看，`fail2ban-client unban <你的IP>` 立即解封 |
| 部署页卡住 / 提示“连接中断” | 部署在服务器上仍在继续。等几秒会自动重连；一直不行就退出重开 App，会自动接上。失败时点错误卡片上的“复制诊断信息”发给开发者 |
| 授权已失效，请重新配对 | 令牌被撤销或密钥被移除，点“重新配对”输入 SSH 密码 |
