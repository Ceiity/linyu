# QQ 机器人主人指令文档

本文档整理的是 QQ/群聊里由“机器人主人”直接发送文字触发的远程管理指令，不是 Web 面板 HTTP API。

源码位置：

- 插件入口：`plugins/astrbot_plugin_nailong_remote_admin/main.py`
- 插件说明：`plugins/astrbot_plugin_nailong_remote_admin/README.md`

## 当前数量

按“功能”统计，目前一共 **6 个主人可用功能指令**：

1. 申请扫码登录
2. 创建机器人
3. 开启全员申请登录
4. 关闭全员申请登录
5. 应用 AstrBot 群聊免 @ / 免前缀配置
6. 删除机器人

如果按“实际可发送的文字口令”统计，一共 **10 个口令**：

- `申请登录`
- `创建机器人`
- `删除机器人`
- `登录开启`
- `登录关闭`
- `无需@无需前缀`
- `无需at无需前缀`
- `无需at无需前戳`
- `免@免前缀`
- `免at免前缀`

## 权限规则

| 项目 | 默认值 | 说明 |
|---|---|---|
| 主人 QQ | 未设置（需在面板「系统设置」填写） | 只有配置在 `owner_ids` 里的 QQ 可以执行主人指令。 |
| 响应机器人 QQ | 未设置（需在面板「系统设置」填写） | 只有配置在 `bot_self_ids` 里的机器人账号会响应。 |
| 群限制 | 默认不限制 | 如果配置了 `allowed_groups`，只在指定群响应。 |
| 远程 Token | 面板生成 | 插件调用面板 Remote API 时通过 `X-Remote-Token` 鉴权。 |
| 冷却时间 | 默认 60 秒 | `申请登录` 有冷却，避免频繁刷二维码。 |

## 指令详情

### 1. 申请登录

| 项目 | 内容 |
|---|---|
| 指令 | `申请登录` |
| 使用者 | 主人默认可用；开启全员申请后普通用户也可用。 |
| 作用 | 自动申请一个 NapCat 扫码机器人，并把二维码发到聊天里。 |
| 后端调用 | `POST /api/remote/napcat/create-login` |
| 成功反馈 | 发送二维码图片；扫码成功后发送 QQ 头像、昵称、QQ 号、服务器信息。 |

流程：

1. 用户/主人发送 `申请登录`。
2. 插件向面板申请空闲 NapCat。
3. 面板优先复用空闲实例；没有空闲时，主人请求可触发自动创建。
4. 插件发送二维码。
5. 插件最多轮询约 3 分钟。
6. 登录成功后发送成功提示。

---

### 2. 创建机器人

| 项目 | 内容 |
|---|---|
| 指令 | `创建机器人` 或 `创建机器人 数量` |
| 示例 | `创建机器人 3` |
| 使用者 | 仅主人 |
| 数量范围 | 1 到 20，超出会被限制到范围内。 |
| 作用 | 创建指定数量的 NapCat 机器人实例。 |
| 后端调用 | `POST /api/remote/napcat/create` |
| 成功反馈 | 返回任务标题和任务 ID，可去 Web 面板任务进度查看。 |

说明：

- 不写数量时默认创建 1 个。
- 数量解析失败时默认 1 个。
- 插件层限制最大 20 个，避免 QQ 指令误触导致大量创建。

---

### 3. 登录开启

| 项目 | 内容 |
|---|---|
| 指令 | `登录开启` |
| 使用者 | 仅主人 |
| 作用 | 开启“全员申请登录”，普通用户也可以发送 `申请登录` 获取二维码。 |
| 后端调用 | `POST /api/remote/login/public-access` |
| 成功反馈 | 提示已开启全员申请登录。 |

---

### 4. 登录关闭

| 项目 | 内容 |
|---|---|
| 指令 | `登录关闭` |
| 使用者 | 仅主人 |
| 作用 | 关闭“全员申请登录”，恢复为只有主人可以申请。 |
| 后端调用 | `POST /api/remote/login/public-access` |
| 成功反馈 | 提示已关闭全员申请登录权限。 |

---

### 5. 应用免 @ / 免前缀配置

| 项目 | 内容 |
|---|---|
| 主指令 | `无需@无需前缀` |
| 别名 | `无需at无需前缀`、`无需at无需前戳`、`免@免前缀`、`免at免前缀` |
| 使用者 | 仅主人 |
| 作用 | 应用 AstrBot 群聊无需 @ / 无需前缀唤醒配置。 |
| 后端调用 | `POST /api/remote/astrbot/no-prefix` |
| 成功反馈 | 返回任务 ID，完成后 AstrBot 自动应用新设置。 |

匹配规则：

- 插件会去掉空白并转小写后匹配。
- 所以类似 `无需 @ 无需 前缀` 这种带空格写法也能被归一化匹配到对应口令。

---

### 6. 删除机器人

| 项目 | 内容 |
|---|---|
| 指令 | `删除机器人 名称` |
| 示例 | `删除机器人 napcat-1` |
| 使用者 | 仅主人 |
| 默认行为 | 删除容器和索引记录，默认保留数据目录。 |
| 后端调用 | `POST /api/remote/napcat/delete` |
| 成功反馈 | 返回任务标题和任务 ID，可去 Web 面板任务进度查看。 |

说明：

- 该指令只允许主人使用。
- 名称优先匹配真实容器名，例如 `napcat-1`。
- 如果只输入数字，例如 `删除机器人 1`，后端会按当前 NapCat 索引列表顺序删除第 1 个机器人。
- 为了避免误删用户数据，QQ 指令默认 `keep_data=true`，也就是保留实例数据目录。

## 指令总表

| 功能 | 可发送文本 | 权限 | 对应后端 Remote API |
|---|---|---|---|
| 申请扫码登录 | `申请登录` | 主人；或全员登录开启后所有允许范围内用户 | `/api/remote/napcat/create-login` |
| 创建机器人 | `创建机器人`、`创建机器人 3` | 仅主人 | `/api/remote/napcat/create` |
| 删除机器人 | `删除机器人 napcat-1`、`删除机器人 1` | 仅主人 | `/api/remote/napcat/delete` |
| 开启全员登录 | `登录开启` | 仅主人 | `/api/remote/login/public-access` |
| 关闭全员登录 | `登录关闭` | 仅主人 | `/api/remote/login/public-access` |
| 免 @ / 免前缀 | `无需@无需前缀` 等 5 个别名 | 仅主人 | `/api/remote/astrbot/no-prefix` |

## 目前还没有做成 QQ 指令的能力

下面这些能力 Web 面板里有，但目前没有对应“主人发 QQ 指令”的入口：

- 启动 / 停止 / 重启指定 NapCat
- 查看机器人池状态
- 查看任务进度
- 查看日志
- 创建备份 / 恢复备份
- 更新 AstrBot / NapCat / 全部组件
- 重启 watchdog
- 修改面板设置
- 修改面板密码
- 文件中心上传/删除/分享

如果后续要继续产品化，建议优先补这几个主人指令：

1. `机器人状态`：返回机器人池概览。
2. `任务列表`：返回最近运行中任务。
3. `重启机器人 名称`：远程重启指定 NapCat。
4. `更新全部`：触发全量更新任务，仅主人可用。
